💡 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

PROBLEM: No audio captured on server
SOLUTION: 
    pactl list sources short
    # Find your monitor device, then:
    pactl set-default-source <YOUR_MONITOR_SOURCE>

PROBLEM: Can't connect to server
SOLUTION:
    1. Check both laptops are on same network
    2. Check firewall: sudo ufw allow 9999/tcp
    3. Verify server is running: netstat -tulpn | grep 9999

PROBLEM: Audio is choppy
SOLUTION:
    1. Check network connection quality
    2. Close other network-intensive applications
    3. Move closer to WiFi router

PROBLEM: No sound on client
SOLUTION:
    1. Check volume on destination laptop
    2. Check audio output device is working: speaker-test
