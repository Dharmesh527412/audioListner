                        DATA FLOW SEQUENCE

═══════════════════════════════════════════════════════════════════

1. 🎵 Music plays in Brave Browser
        ↓
2. 🔊 PulseAudio Monitor captures the audio
        ↓
3. 📊 audio_server.py reads from monitor device
        ↓
4. 📦 Server packages audio into network packets
        ↓
5. 🌐 TCP socket transmits over local network
        ↓
6. 📡 audio_client.py receives packets
        ↓
7. 🎧 Client plays audio through speakers
        ↓
8. 🎉 You hear the music on Laptop 2!


═══════════════════════════════════════════════════════════════════

                      TECHNICAL SPECIFICATIONS

═══════════════════════════════════════════════════════════════════

Audio Quality:
  - Sample Rate: 44,100 Hz (CD Quality)
  - Channels: 2 (Stereo)
  - Bit Depth: 32-bit float
  - Block Size: 2,048 frames

Network:
  - Protocol: TCP/IP
  - Port: 9999 (default)
  - Buffer: 50 frames
  - Latency: ~100-300ms (typical)

Compression: None (raw audio)
Encryption: None (local network only)

                        COMMAND SUMMARY

═══════════════════════════════════════════════════════════════════

On LAPTOP 1 (Server):
  ./start_server.sh

On LAPTOP 2 (Client):
  ./start_client.sh <SERVER_IP>

Transfer to Laptop 2:
  ./copy_to_laptop.sh portable
  or
  ./copy_to_laptop.sh user@laptop-ip

                    MULTIPLE CLIENTS SUPPORT

═══════════════════════════════════════════════════════════════════

One server can stream to MULTIPLE clients simultaneously!

    ┏━━━━━━━━━━━━━━━┓
    ┃    SERVER     ┃
    ┃   Laptop 1    ┃
    ┗━━━━━━┯━━━━━━━━┛
